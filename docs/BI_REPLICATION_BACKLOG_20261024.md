## 第五批：视窗体系核心（本轮实施）

对应差距矩阵 **P1 #5**（视窗：上限约束 + 个人/默认双轨）与 **P1 #10**（视图进 URL）。

| # | 项 | 验收 |
|---|---|---|
| 5a | 字段选择器上限约束（`maxSelected`） | 勾满上限后未选字段自动禁用；全选不超过上限；计数「已选 X / 25」 |
| 5b | 个人视窗：保存 / 应用 / 恢复默认 | 「保存为个人视窗」落 settings（`product_personal_view`）；工具栏出现「个人视窗」快切；「恢复默认视窗」清空回退 |
| 5c | 视图进 URL（`?view=`） | 切换模板/个人视窗时 URL 同步；带参打开直达该视图；custom 不写参 |

设计取舍（相对 BI 原版）：
- BI 的「个人视窗/默认视窗」是抽屉里的两列模板清单；我们已有服务端模板体系（8 内置 + 自定义），故**默认视窗轨 = 既有模板**，**个人视窗 = 单槽快存**（一份列清单 + 保存时间），语义等价、改动面最小。
- 上限取 25（BI `maxNum` 同值）；只拦「新增勾选」不截断存量（老偏好里超 25 列的照常显示，减到上限内才能再增）。
- 详情页 TAB 已用 `#hash` 同步、列表模式已有 `product_view` 参数，本轮只补模板/个人视窗的 `?view=`。
