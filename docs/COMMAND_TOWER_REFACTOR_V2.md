# 六边形指挥塔重构方案 - V2.0

## 🎯 现状问题分析

### 核心问题：
1. **功能分散**：40+个独立页面，每个页面只解决单一问题
2. **导航混乱**：菜单项重复（两个analysis子菜单），没有统一入口
3. **缺少闭环**：没有把"数据→分析→决策→执行→复盘"串联起来
4. **效率低下**：运营人员需要在多个页面之间反复跳转

### 现有页面清单：
```
数据概览
商品中心（商品列表、渠道分析）
数据分析（KPI分析、利润分析、趋势分析、同比对比、四象限分析、广告投放、多渠道推广、商品排行榜、流量分析、推广效果分析）
运营监控（健康度评分、库存预警、操作统计、退款分析、异常告警、数据备份、批量导入）
六边形指挥塔（人群资产归因、策略实验与SOP、人效精准度量、智能告警中心）
可视化工具（高级图表、AI智能分析）
运营工具（生命周期、预测分析、数据质量、评价分析、市场分析、目标管理、Pace监控、异动归因、漏斗转化）
智能工具（智能选品、自动报告、运营工具箱）
系统管理（数据导入、数据备份、系统设置）
```

## 🎨 重构方案设计

### 核心理念：**一个主驾驶舱，四个指挥中心**

#### 一、主驾驶舱：六边形指挥塔（首页）
把所有核心功能整合在一个页面，实现一站式运营指挥！

##### 布局结构：
```

├─────────────────────────────────────────────────────────────────────────────┤
```

#### 二、四个指挥中心（点击六边形卡片进入）

### 🎯 指挥中心一：数据与目标（Data & Goals）
整合所有数据类功能到一个页面！

**功能模块**：
1. **数据概览看板**（旧版首页）
2. **商品分析中心**：商品列表 + 排行榜 + 商品详情 + 四象限
3. **流量分析中心**：流量概览 + 来源分析 + 关键词分析
4. **推广分析中心**：多渠道推广 + 直通车 + 引力魔方 + 万相台 + 淘客
5. **利润与KPI中心**：KPI分析 + 利润分析 + 趋势分析 + 对比分析

**页面布局**：
```
[左侧导航菜单] | [右侧主内容区域]
───────────────────────────────────
数据概览         |
商品分析         | (可切换标签页)
流量分析         |
推广分析         |
利润分析         |
```

## 🎯 核心设计要点

### 1. 六边形卡片设计
每个六边形卡片都包含：
- 关键数据概览
- 趋势小图
- 快速操作按钮
- 跳转入口

### 2. 时间范围统一
所有数据使用统一的时间选择器，一次设置，全系统生效

### 3. 告警联动
告警信息在所有指挥中心顶部都有显示，点击可快速处理

### 4. 拖拽布局
允许用户自定义驾驶舱布局，把最关注的模块放在最前面
