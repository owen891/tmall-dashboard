# 商品分类字典与中文化设计

## 目标

让运营人员在设置页管理商品分层、风格、生命周期和季节属性，并确保所有业务页面只显示中文名称。系统继续使用稳定内部编码保存生命周期和季节属性，兼容现有数据、筛选、历史记录和自动判断逻辑。

## 字段规则

| 字段 | 系统值 | 可新增 | 可改中文名称 | 可停用 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 分层 | 用户定义文本 | 是 | 是 | 是 | 例如爆款、引流款、利润款 |
| 风格 | 用户定义文本 | 是 | 是 | 是 | 例如通勤、休闲、轻奢 |
| 生命周期 | 稳定英文编码 | 是，仅人工分类 | 是 | 是 | 系统内置阶段编码不可删除或修改 |
| 季节属性 | 稳定英文编码 | 是，仅人工分类 | 是 | 是 | 系统内置属性编码不可删除或修改 |

系统内置生命周期包括数据积累中、新品期、成长期、爆发期、成熟期、衰退期和清退期。系统内置季节属性包括常年稳定型、春夏型、秋冬型、单峰季节型、双峰季节型、节日/大促驱动型和人工维护。

## 数据与接口

分类字典存入现有设置存储，新增 `classification_dictionaries` 配置项，按 `tiers`、`styles`、`lifecycle_stages`、`seasonal_attributes` 分组。每项包含稳定 `value`、中文 `label`、是否启用 `enabled` 和是否为系统内置 `system`。

设置接口返回完整字典；更新时校验组名、唯一值、非空中文名称和系统项保护规则。旧数据库没有该配置时自动返回默认字典。已有商品值不在当前字典时仍保留并显示，避免历史数据丢失。

生命周期更新接口接受当前启用字典中的值。系统算法只产出内置编码；新增的自定义生命周期和季节属性只能由人工选择。

## 页面交互

设置页新增“商品分类字典”区域，以四个紧凑列表管理分类。支持新增、改名、启用和停用；系统内置项锁定编码。保存沿用设置页现有保存动作和状态反馈。

商品页的分层和风格批量编辑使用带候选项的可输入控件：可以选择已有项，也能直接输入新值。新值保存商品后同步进入字典，减少重复配置操作。

生命周期调整对话框从设置字典生成选项。商品列表筛选、生命周期表格、历史记录、置信度和来源统一通过中文映射显示。未知旧值显示原值并标记为历史值，不阻断页面。

## 兼容与错误处理

- 停用项不再出现在新增和编辑候选中，但现有商品仍显示原中文名称。
- 系统项不能删除、改编码或转为非系统项。
- 分类改名只改变显示名称，不批量重写历史数据。
- 重复编码、空名称、未知字典组或破坏系统项的请求返回 `422 VALIDATION_ERROR`。
- 保存失败时保留表单内容并显示后端错误，不做部分更新。

## 测试与验收

- 设置 API 默认返回四组中文字典，并可持久化新增、改名和停用操作。
- 系统项保护、重复值和空名称校验有失败测试。
- 生命周期接口允许启用的自定义人工分类，拒绝未知或停用分类。
- 商品页、生命周期页不直接显示已知英文枚举。
- 现有设置、商品筛选、生命周期历史和导入相关测试保持通过。
- 桌面与移动宽度下检查设置列表和生命周期编辑对话框无溢出、遮挡或不可操作控件。
