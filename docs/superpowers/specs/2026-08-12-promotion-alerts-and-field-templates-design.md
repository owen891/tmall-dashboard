# 推广预警与字段模板设计

## 目标

将推广分析从固定 ROI 预警升级为可组合的规则系统，并让五个推广视图分别保存自己的字段模板。推广商品列表同时通过商品 ID 关联商品运营主图，使用户能在同一页面识别商品、筛选字段并配置预警。

## 范围

本次包含：

- 推广商品、投放关键词、人群分析、创意分析、内容与地域五个视图各自维护字段模板。
- 预警规则支持任意层级的 AND / OR 条件组。
- 预警条件可自由选择字段、运算符和值。
- 提供推荐预警模板，并支持保存多个自定义模板。
- 推广商品按商品 ID 关联商品运营主图，未关联时明确显示占位状态。

本次不包含真实后端持久化、跨账号共享、消息通知渠道接入和规则定时执行引擎；演示页以内存状态呈现完整交互。

## 信息架构

推广页保留五个分析视图：

1. 推广商品
2. 投放关键词
3. 人群分析
4. 创意分析
5. 内容与地域

每个视图的工具栏只显示一套“字段模板”控制。模板选择器、字段选择器和模板管理入口合并在同一个弹出面板内，避免重复入口。

字段模板按视图隔离保存。用户在“推广商品”保存的模板不会出现在“投放关键词”中；切换视图时自动恢复该视图上次使用的模板。模板数据结构包含视图标识、模板名称、字段顺序、显示字段和当前启用状态。

## 字段模板

每个视图内提供：

- 2 至 3 个系统推荐模板，覆盖该视图最常见的分析任务。
- “自定义模板”入口，允许勾选字段、调整字段顺序并命名保存。
- 模板的应用、重命名和删除操作；系统模板不可删除。
- 当前模板和当前字段数量的清晰状态反馈。

推荐模板按视图配置，不强行共用字段集合。例如推广商品侧重商品、花费、点击、成交和 ROI；关键词侧重关键词、匹配方式、展现、点击、CTR、CPC 和转化；内容与地域侧重内容类型、地域、流量、花费、成交和 ROI。

## 预警规则构建器

预警抽屉由三部分组成：预警模板、规则构建器和执行设置。

规则树以条件组为基本单位：

- 每个组选择 AND 或 OR。
- 组内可新增条件或子条件组。
- 子组可以继续嵌套，不限制产品层面的组合形式。
- 每条条件包含字段、运算符和值。
- 数值字段支持 `<`、`<=`、`>`、`>=`、`=`、`!=` 和“区间”。
- 枚举字段只显示适用的等于、不等于和包含类运算符。
- 删除最后一条条件时保留一个空条件，避免出现不可编辑的空规则。

规则示例：

`ROI < 3 AND (点击量 > 500 OR 花费 > 1000)`

字段选项至少覆盖 ROI、花费、展现量、点击量、CTR、CPC、成交金额、成交笔数和转化率。字段改变时，运算符和值输入控件同步更新，避免无效组合。

## 预警模板

系统提供以下推荐模板：

- 低效消耗：花费较高且 ROI 偏低。
- 高点击低转化：点击量达到阈值但转化率偏低。
- 高花费零成交：花费达到阈值且成交笔数为零。
- 曝光不足：观察期内展现量低于阈值。
- 点击异常：点击量或 CTR 超出合理区间。

应用推荐模板后，规则树变为可编辑副本，不修改系统模板。用户可将当前规则另存为多个自定义模板。每条预警还包含名称、观察天数、严重程度、建议动作和启用状态。

字段模板与预警模板是两套独立概念：字段模板控制表格显示，预警模板控制规则树。两者入口、命名和状态提示必须明确区分。

## 商品主图关联

推广商品行使用商品 ID 查询商品运营数据中的主图 URL：

1. 商品 ID 命中且有主图时，显示缩略图、商品名称和商品 ID。
2. 商品 ID 命中但主图缺失时，显示“暂无主图”占位图。
3. 商品 ID 未命中时，显示“未关联商品”占位状态，不猜测或伪造关联。

当前演示数据中 `985897754523` 和 `1011889511510` 可复用商品运营主图；`971290805262` 保持未关联占位，直到商品运营数据出现相同 ID。

## 状态与反馈

- 新增、删除或切换 AND / OR 后，规则摘要即时更新。
- 条件未填完整时允许继续编辑，但保存按钮禁用，并定位首个无效条件。
- 自定义模板名称在同一类型、同一视图内必须唯一。
- 删除模板需要二次确认；应用模板、保存模板和保存预警使用轻量成功提示。
- 所有图标按钮提供可访问名称，键盘可完成新增、删除、切换和保存操作。

## 实现边界

演示页延续现有静态 HTML、CSS 和原生 JavaScript 结构，不引入新依赖。状态保存在当前页面内存中；数据结构应与后续 API 持久化兼容，但本次不设计服务端接口。

为避免 `promotion.html` 中的交互脚本继续膨胀，规则树操作、字段模板状态和商品图片映射应以独立的数据对象和小型渲染函数组织，各部分只通过明确的状态更新函数通信。

## 验收标准

- 五个视图均能独立应用和保存字段模板，切换视图不会串用模板。
- 用户能构建并编辑 `ROI < 3 AND (点击量 > 500 OR 花费 > 1000)`。
- 推荐预警模板可一键载入，自定义预警模板可保存多套。
- 字段变化会带动运算符和值控件变化，未完成规则不能保存。
- 推广商品正确显示两张已关联主图，并对未关联商品显示明确占位。
- 桌面与移动端无文字遮挡、控件溢出或不可点击区域。
- 结构校验、交互冒烟测试、控制台检查和截图检查通过。

## 验证方案

先在 `scripts/validate_ui_demos.cjs` 增加结构断言，覆盖五类字段模板、嵌套条件组、推荐预警模板和商品图片关联标识，并确认旧实现无法通过。完成页面改造后运行结构校验、`git diff --check`，再通过浏览器分别验证桌面和移动端的模板隔离、嵌套规则编辑、校验反馈、主图关联与控制台零错误。
