# 商品列表筛选工具栏设计

## 目标

将商品列表当前一排等权筛选控件重构为可扫描、可收纳的查询工具栏，降低搜索、核心筛选、排序与低频条件之间的视觉竞争，同时保留现有筛选参数和交互行为。

## 结构

- 第一行：搜索框、分层、生命周期、状态、排序字段、排序方向，以及重置和收藏操作。
- 第二行：风格、季节属性、待办动作等低频条件；默认隐藏，点击“更多筛选”展开。
- 工具栏使用现有 tokens、按钮、输入框和分段控件，不引入新颜色或新依赖。
- `data-products-*` 属性保持不变，产品取数、筛选和分页逻辑不改。

## 响应式

- 桌面端第一行采用弹性网格，搜索框占据主要宽度，筛选项保持稳定最小宽度。
- 中等宽度允许核心条件换到下一行，但操作按钮保持右侧对齐。
- 移动端改为单列，搜索框全宽；更多筛选展开后按单列排列，避免控件内部换行。

## 验证

- 桌面 1366px、平板 768px、手机 390px 检查控件不重叠、不溢出。
- 搜索、核心筛选、更多筛选、重置和当前页收藏的原有选择器与事件保持可用。
