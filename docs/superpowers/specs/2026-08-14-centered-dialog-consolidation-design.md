# 居中弹窗统一设计规格

## 目标

将业务下钻和工具流程统一为居中弹窗，移除右侧抽屉交互。解决当前工具箱占满视口、内容空白过多、滚动距离长，以及不同页面弹层行为不一致的问题。

## 范围

- 全局“数据工具箱”：右侧抽屉改为居中工作流弹窗。
- 推广“数据口径说明”：右侧详情抽屉改为居中详情弹窗。
- 商品详情弹窗：将长页面拆为 Tab，避免指标、趋势、协作信息连续纵向堆叠。
- 商品页：删除已经失效但仍残留在脚本中的旧商品抽屉代码。
- 保持现有商品详情、生命周期详情、字段配置、能力详情等 `<dialog>` 交互不变，只统一尺寸和行为契约。
- 移动端导航侧栏不属于业务下钻，继续保留。

## 交互模型

### 数据工具箱

- 使用原生 `<dialog>`，桌面宽度最大 720px，高度不超过视口减 24px。
- 移动端宽度占可用视口，高度按内容与视口上限共同约束。
- 顶部只保留标题、副标题和关闭按钮。
- “立即导入 / 定时任务”改为紧凑分段控件，不再使用两张大卡片。
- 当前工具内容放在一个无嵌套卡片的工作区中。
- 导入流程显示文件选择区、文件队列/选择结果、主操作按钮、进度和结果。
- 定时任务显示紧凑表单和最近任务表格；表格仅在该模式下出现。
- 弹窗高度由内容决定，内容超过上限时仅正文区域滚动。

### 推广口径详情

- 使用原生 `<dialog>`，桌面宽度最大 680px。
- 保留当前标题、周期副标题、指标说明内容。
- 点击遮罩、关闭按钮或 Escape 均可关闭。
- 关闭后焦点返回触发按钮。

### 商品详情

- 继续使用共享商品详情 `<dialog>`，不恢复任何右侧抽屉。
- 弹窗顶部保留商品名称、商品 ID 和数据截止日期。
- Tab 固定为“经营概览”“日趋势”“生命周期”“协作记录”四项。
- “经营概览”展示商品信息、经营指标和推广指标，是默认 Tab。
- “日趋势”展示日度表格；“生命周期”展示阶段、季节属性和判断依据；“协作记录”合并备注、标签和运营动作。
- 每次切换 Tab 只渲染当前内容，避免隐藏内容继续撑高弹窗。
- 当前 Tab 通过 `aria-selected`、`role=tablist`、`role=tabpanel` 表达，支持左右方向键切换。

## 统一行为契约

- 所有业务弹窗使用 `showModal()` / `close()`。
- 弹窗打开时由浏览器原生模态语义阻止背景交互。
- 首次焦点落在关闭按钮或首个可操作控件。
- Escape 关闭；关闭后恢复触发元素焦点。
- 弹窗正文负责纵向滚动，页面本身不产生额外滚动。
- Tab 弹窗只允许当前面板产生纵向滚动，切换时保留当前弹窗焦点上下文。
- 不再保留 `.toolbox-overlay`、`.toolbox-drawer`、`.demo-drawer` 这类业务抽屉样式。

## 视觉规则

- 延续现有中性运营后台风格，不引入新配色或新依赖。
- 弹窗圆角、边框、阴影继续使用现有 token。
- 标题区、正文区、底部操作区边界清晰。
- 工具模式切换使用 segmented control；关闭按钮使用图标按钮。
- 避免卡片嵌套，导入区和任务区使用分隔线与间距组织。

## 响应式

- 1366px / 1920px：居中定宽弹窗，正文最大高度受视口约束。
- 1024px：保持居中，宽度使用 `calc(100vw - 32px)`。
- 390px：宽度使用 `calc(100vw - 16px)`，表单转单列，任务表格可水平滚动。

## 验证

- 更新静态 UI 契约测试，不再要求工具箱和推广详情抽屉标记。
- 浏览器 smoke 覆盖工具箱、推广口径详情和商品详情 Tab 在 1366、1024、390 三种视口的打开、关闭、视口内布局和横向溢出。
- 检查 Escape、遮罩点击、焦点恢复和 Tab 顺序。
- 前端脚本通过 `node --check`，Python 回归测试保持通过。
