# 工具箱导入预览与映射设计

## 目标

让数据工具箱的经营数据导入在写入数据库前完成预览、字段映射和质量校验，避免用户选择文件后直接进入旧的异步导入流程。

## 交互流程

1. 用户在工具箱选择一个或多个 `.xlsx`、`.xls`、`.csv` 或 `.zip` 文件。
2. 点击“预览并校验”，每个文件依次调用现有 `POST /api/imports/preview`。
3. 预览面板显示文件标签、识别出的报表类型、有效/无效行、日期范围、重复业务键和预计新增/更新。
4. 表格逐列显示原始列、推断类型、标准字段映射、匹配状态和样例值。标准字段由下拉框调整。
5. 必填映射缺失、存在无效行或重复业务键时，禁止确认导入，并在状态区域说明原因。
6. 点击“确认导入”后，按预览顺序调用现有 `POST /api/imports`，成功后显示新增/更新结果。

## 实现边界

- 复用 `services/import_service.py` 已有的预览、映射和质量校验逻辑，不修改数据库表结构。
- 工具箱入口使用与数据中心页面相同的预览接口和确认接口。
- 旧 `/api/upload/data` 进度轮询流程不再用于经营数据工具箱，但保留给其他旧页面和接口。
- 预览内容只保存到现有 `import_previews`，确认前不写入业务事实表。

## 错误处理

- 未选择文件时提示选择文件。
- 单个文件预览失败时保留其他文件的预览，并列出失败文件。
- 确认导入时单个文件失败不影响已成功完成的文件，失败预览保留以便重试。
- Escape 和关闭按钮仍能关闭工具箱；打开预览后焦点留在弹窗内。

## 验收

- 工具箱按钮文字为“预览并校验”，点击后不会调用 `/api/upload/data`。
- 预览面板可见文件列表、字段映射和质量摘要。
- 缺少必填映射、无效行或重复键时确认按钮不可用或点击后被拦截。
- 通过预览后确认导入能写入现有业务表并显示结果。
- 现有导入工作流测试保持通过，并新增工具箱入口契约测试。
