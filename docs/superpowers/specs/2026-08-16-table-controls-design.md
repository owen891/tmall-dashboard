# 全局表格控件设计

## 目标

为 UI Demo 中的业务数据表统一提供可访问的表头排序、页面滚动时的吸顶表头和每页行数/上下翻页控件。商品列表保留现有 API 分页与筛选语义，只把每页条数选择并入现有分页栏。

## 范围

- `.data-table` 业务表格：商品、推广、生命周期、概览、复盘、数据中心、目标、设置、对比、导入预览及弹窗内明细表。
- 复选框、收藏和操作列保留原有交互，不参与排序。
- 其他数据列支持点击或键盘触发升序/降序。
- 非商品表格分页当前 DOM 已加载行；商品列表使用 `/api/products` 的 `limit/offset` 服务端分页。

## 交互设计

- 表头数据列显示排序按钮和方向图标，未排序时为中性状态，排序后更新 `aria-sort` 与图标。
- 排序自动识别数字、金额、百分比、日期和文本，空值排在末尾；相同值保持原顺序。
- 每个表格分页栏显示“每页”选择、上一页、页码/总数摘要、下一页。可选 `20 / 50 / 100 / 200` 行，数据不足一页时按钮禁用但控件保持位置稳定。
- 表格进入顶部导航下方区域且仍有内容时显示固定表头副本；离开表格范围后隐藏。横向滚动时固定副本同步表格滚动位置。
- 弹窗中的表格以弹窗标题/顶部为吸顶边界，不遮挡关闭和操作区域。

## 架构

新增 `frontend/ui_demo/assets/table-controls.js`，由 `shell.js` 在所有应用页加载。模块使用 `MutationObserver` 监听动态表头和表体，避免改造每个页面的渲染函数。每个表格以 `WeakMap` 保存排序、分页和固定表头状态；排序和分页只重排当前 DOM 行，不改后端数据和行内事件监听。

商品列表标记为服务端分页表，现有 `products-live.js` 继续负责请求、筛选和页码；新增的每页选择驱动 `state.pageSize` 并传给 API。通用模块跳过该表，避免双重分页。

## 验证

- 浏览器验证所有主要页面表头可排序、滚动吸顶、分页栏可切换行数且按钮状态正确。
- 商品页验证每页条数改变后 API 请求、摘要和上下页同步。
- 验证含按钮、复选框、弹窗明细的表格行内操作仍可用。
- 运行 JavaScript 语法检查、现有 UI/API 测试和 `git diff --check`。
