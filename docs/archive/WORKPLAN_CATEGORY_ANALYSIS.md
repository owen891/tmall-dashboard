# 品类周期分析与利润分析 Workplan

**项目**: tmall-dashboard  
**开始日期**: 2026-09-20  
**目标**: 完成日 / 周 / 月 / 自定义周期的品类对比分析，并接入可解释的利润分析。v1.1 已完成常态化品类经营看板，后续按本计划补齐数据源与成本能力。

## 1. 交付范围

- 品类筛选

- 去年同期、上一周期、自定义周期对比

- 销售额、净销售额、转化率、客单价等经营指标
- 部分成本经营利润
- 利润拆解和成本完整度提示

- API、页面、测试和验收文档
- 独立常态化品类经营看板入口；自定义分析继续作为临时取数工具

## 4. 关键风险

| 风险 | 影响 | 处理方式 |
| --- | --- | --- |
| 周度数据不是自然周 | 周同比失真 | 统一规范为周一至周日，并保留实际日期 |
| 月度数据缺少日度明细 | 无法支持任意区间 | 自定义区间只使用 `daily_data`，不足时明确不可用 |
| 利润成本字段不完整 | 利润结果被误解 | 返回 `partial` 和缺失成本列表 |
| 比例指标直接平均 | 转化率、利润率错误 | 使用聚合后的分子分母计算 |
| 当前周/月未结束 | 同比偏低或偏高 | 使用同天数同期并显示部分周期 |
| 品类配置重复 | 筛选结果不一致 | 复用现有 `category_mode` 服务 |
| 前端保留旧 fallback | API 口径不一致 | 新页面只调用统一分析接口 |

## 5. 第一版完成定义

第一版达到以下条件即可交付：

1. 选择品类后能查看日、周、月和任意日期区间。
2. 支持去年同期、上一周期和自定义周期。
3. 支持销售额、净销售额、推广花费和经营利润。
4. 展示总值、日均值、差值、增长率。
5. 展示利润拆解和缺失成本提示。
6. 支持商品增长贡献排行。
7. API 和前端测试通过。
