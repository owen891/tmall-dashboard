- **文件**: `scripts/auto_login_bi.py:20-22`, `scripts/auto-collect.ps1:29-30`

### 2. 🔴 生产预检会修改数据库
- **文件**: `scripts/production_preflight.py:95-100`, `app.py:140`, `db.py:941-1209`
- **问题**: "只读检查"实际执行 ALTER TABLE、重建数据
- **行动**:
  1. 预检使用临时副本或只读连接
  2. Schema 迁移与应用启动解耦
  3. 真实迁移通过独立命令执行

### 3. 🔴 桌面发布跳过 Python 测试
- **文件**: `.github/workflows/desktop-release.yml:62-70, 108-119`
- **问题**: 使用 `-SkipPythonTests`，后端回归可直接打包
- **行动**:
  1. 桌面发布增加完整 Python 测试步骤
  2. 或强制依赖 `quality-gate.yml` 通过

### 4. 🔴 数据库迁移机制缺失
- **文件**: `migrations/` 空目录, `db.py:85-1221` 隐藏迁移
- **问题**: 新环境无法标准重建，升级不可审计
- **行动**:
  1. 拆分为独立 Alembic migration 文件
  2. 应用启动只检查版本，不执行迁移
  3. 提供 `alembic upgrade head` 标准路径
