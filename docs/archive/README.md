# Archived Design References

This directory documents historical, non-runtime assets kept for context.

- `../refactor_demo/` is the earlier ORM/Vite refactor proposal. The current project reuses the existing Flask API and vanilla frontend.
- `../../dashboard-prototype/` contains earlier visual prototypes and validation traces.
- `../ui_demo/` is the original source copy; runtime serves `../../frontend/ui_demo/`.
## 归档说明

`docs/ui_demo/` 是迁移前的静态设计稿与历史演示资产，不属于当前发布入口，可能保留旧版 Chart.js 引用。当前主应用只使用 `frontend/ui_demo/`，图表统一使用 ECharts；主入口为 Flask 路由 `/` 及七个正式页面。
